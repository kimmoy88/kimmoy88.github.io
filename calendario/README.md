# Calendario de evaluaciones

App web para llevar las fechas, los pesos y las notas de las evaluaciones de cada materia.
Se puede instalar en el teléfono como una app y funciona sin conexión.

## Qué hace

- Muestra el mes con las evaluaciones de cada materia, cada una con su color.
- Deja agregar, editar y eliminar evaluaciones y materias.
- Convierte cada nota a escala de 20 y calcula el acumulado de cada materia.
- Lista las próximas fechas con los días que faltan.

## Dónde se guardan los datos

Los datos se guardan solo en el navegador de cada dispositivo. No se envían a ningún servidor.
Para respaldarlos o pasarlos a otro dispositivo, usa «Exportar copia» y luego «Importar copia» al final de la página.

## Instalarla en el teléfono

- iPhone: abre la página en Safari, toca el botón de compartir y elige «Agregar a inicio».
- Android: abre la página en Chrome, toca el menú y elige «Instalar app» o «Agregar a pantalla principal».

## Archivos

- `index.html`: la app completa.
- `manifest.webmanifest` y `sw.js`: instalación y uso sin conexión.
- `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` y `apple-touch-icon.png`: íconos.
